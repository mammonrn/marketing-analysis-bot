# Average BIn by Week Day × Hour Reference
## ไฟล์: "Average BIn (Week Day x Hour).xlsx" และ "Average BIn Mems (Week Day x Hour).xlsx"
## ใช้กับ shwe666 / ubet89 / 88fed

ตาราง pivot 7 วัน × 24 ชั่วโมง บอกว่าเงินฝาก (หรือจำนวนคนฝาก) กระจุกอยู่ช่วงไหน
ของสัปดาห์ เป็น **snapshot** — ผูกกับเดือนที่อัปโหลด

**ไฟล์สองตัวนี้มี header เหมือนกันทุกตัวอักษร** (`Hour`, 0, 1, ... 23)
แยกจากกันด้วยชื่อไฟล์เท่านั้น — มีคำว่า `Mems` = นับจำนวนคน, ไม่มี = นับยอดเงิน

---

## รูปแบบไฟล์ดิบ

```
แถวที่ 1: Hour | 0 | 1 | 2 | ... | 23        ← header จริง
แถวที่ 2: Week Day | Average of Points | ...  ← sub-header (ไม่ใช่ข้อมูล)
แถวที่ 3-9: 1..7 | ค่าเฉลี่ยรายชั่วโมง         ← ข้อมูลจริง (1 = จันทร์ ... 7 = อาทิตย์)
แถวสุดท้าย: "Applied filters: ..."            ← ท้ายตาราง (ไม่ใช่ข้อมูล)
```

คอลัมน์แรกหัวตารางเขียนว่า `Hour` แต่เนื้อในเป็น**วันในสัปดาห์** — เป็นวิธีที่
Power BI ตั้งชื่อแกนของ pivot ไม่ใช่ความผิดพลาด

## รูปแบบหลังแปลง (ที่บอทเก็บจริง)

แปลงเป็น 168 แถว (7 × 24) แถวละ:

| Column | ความหมาย |
|--------|----------|
| **weekday** | ชื่อวัน `Monday` ... `Sunday` |
| **weekday_num** | 1-7 สำหรับเรียงลำดับ |
| **hour** | ชั่วโมง 0-23 |
| **avg_bin** | ยอดฝากเฉลี่ย (ไฟล์ที่ไม่มีคำว่า Mems) |
| **avg_mems** | จำนวนคนฝากเฉลี่ย (ไฟล์ที่มีคำว่า Mems) |

---

## Metric หลักที่ควรพูดถึงเวลามีคนถาม

1. **ช่วงพีค** — ชั่วโมงและวันที่ `avg_bin` สูงสุด ใช้ตอบว่าควรยิงแอด
   หรือปล่อยโปรตอนไหน
2. **ช่วงเงียบ** — ชั่วโมงที่ต่ำสุดติดต่อกัน เหมาะกับงาน maintenance
   หรือทดสอบระบบ
3. **เงินเยอะเพราะคนเยอะ หรือเพราะฝากหนัก** — เทียบสองไฟล์คู่กัน
   `avg_bin` สูงแต่ `avg_mems` ไม่สูง = ช่วงนั้นมีลูกค้ารายใหญ่ฝาก
   ถ้าสูงทั้งคู่ = คนเยอะจริง
4. **เสาร์-อาทิตย์ต่างจากวันธรรมดาไหม** — เทียบ weekday_num 6-7 กับ 1-5

> ตัวเลขเป็น**ค่าเฉลี่ย**ต่อช่อง ไม่ใช่ยอดรวม — อย่าเอาไปบวกกันเป็นยอดรวมทั้งวัน
